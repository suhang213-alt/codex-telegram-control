# Установка: существующий Codex Desktop на Mac → Telegram на Samsung

Эта инструкция подключает существующие локальные чаты Desktop. Пакет остаётся кандидатом до [реальной приёмки](MOBILE_ACCEPTANCE.md). Отдельный Codex CLI устанавливать и авторизовывать не требуется.

## 1. Подготовьте Mac и тестовый чат

Установите официальное приложение с [страницы OpenAI](https://chatgpt.com/download/) и выполните вход обычным способом. Текущие требования OpenAI — macOS 14+, Apple Silicon либо Intel. Название приложения может быть Codex или ChatGPT с режимом Codex; ChatGPT Classic не подходит. [Источник требований](https://help.openai.com/en/articles/9275200-downloading-the-chatgpt-macos-app), проверен 24.10.2026.

Адаптер принимает проверенную подпись OpenAI и ожидаемую структуру встроенного движка. Наличие подходящей ОС само по себе не подтверждает совместимость конкретной сборки. Если проверка отклонена, не отключайте подпись или защиту macOS.

Выберите отдельную рабочую папку, уже подключённую к Desktop. Для первого испытания создайте там тестовый чат с искусственными данными. Именно этот существующий чат позднее должен открыться на телефоне. Запишите полный путь папки. Не выбирайте домашнюю папку, корень диска, каталог настроек моста или профиль Desktop. Все подходящие локальные чаты в этой папке и её подпапках войдут в область доступа бота.

Распакуйте пакет в обычную папку пользователя. Откройте Terminal, напечатайте `cd `, перетащите распакованную папку в окно и нажмите Enter. В ней должны быть `pyproject.toml` и `scripts`.

Нужен Python 3.11+. Для первой установки подойдёт актуальная universal2-сборка Python 3.12 или 3.13 с [python.org](https://www.python.org/downloads/macos/). Библиотека системного Keychain указывает поддержку macOS 11+ с universal2 Python; требования самого Desktop выше. [keyring](https://pypi.org/project/keyring/).

```sh
python3 --version
```

## 2. Создайте собственного бота и получите свой ID

Создайте **нового отдельного бота** командой `/newbot` в официальном BotFather. Полученный токен храните как пароль; не помещайте его в команды терминала, переписку или issue. [Инструкция Telegram](https://core.telegram.org/bots/tutorial#obtain-your-bot-token).

Из папки пакета выполните:

```sh
python3 scripts/identify-owner.py
```

Введите токен скрыто. Скрипт покажет случайную команду `/identify …`. В течение трёх минут отправьте точно её в личный чат своего бота. Terminal выведет ваш числовой owner ID; он понадобится при настройке. Скрипт не отправляет сообщения, не сохраняет токен и не использует стороннего бота.

Другой polling-процесс этого бота должен быть остановлен. Бот с настроенным webhook для этого сценария не подходит.

## 3. Получите HTTPS-адрес панели

Для первого испытания установите `cloudflared` по [официальной инструкции Cloudflare](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/). Если вы уже используете Homebrew, доступна команда `brew install cloudflared`. Установщик бота не устанавливает туннель автоматически.

В отдельном окне Terminal запустите:

```sh
cloudflared tunnel --url http://127.0.0.1:8787
```

Скопируйте выданный HTTPS-адрес `…trycloudflare.com`. Для настройки нужен только origin: без пути и параметров. Пока мост не запущен, ошибка доступа к локальному origin ожидаема. Оставьте окно туннеля открытым.

Quick Tunnel предназначен для испытаний: аккаунт не требуется, адрес временный, постоянная доступность не гарантируется. Трафик панели проходит через оператора туннеля. [Официальные ограничения](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).

## 4. Установите мост

В первом окне Terminal, из корня пакета:

```sh
bash scripts/install-macos-desktop.command
```

`chmod` перед запуском не нужен. Скрипт создаёт `.venv`, скачивает Python-зависимости и запускает настройку. Ответьте на приглашения:

| Приглашение | Что указать |
|---|---|
| Installed app bundle | Enter для поиска единственной установки либо путь к своей официальной `.app` |
| Numeric Telegram user ID | Число из шага 2 |
| Existing workspace | Полный путь папки существующего тестового чата |
| HTTPS origin | Адрес туннеля из шага 3 |
| Existing Desktop profile | Enter для обычного `~/.codex`; иной путь только если ваш Desktop уже использует его |
| BotFather token | Введите токен скрыто для сохранения в Keychain |

Если найдено несколько приложений, укажите точное установленное приложение. После неуспешного поиска повторите настройку, например:

```sh
.venv/bin/codex-telegram-desktop setup --app-bundle /Applications/Codex.app
```

Пример пути подходит только для установки с таким названием. Проверяется подпись и содержимое, а не имя `.app`.

При системном запросе доступа к Keychain проверьте, что он относится к вашему Python и текущей настройке, затем разрешите доступ, если согласны. При ошибке хранилища разблокируйте Keychain. Если конфигурация ещё не создана — повторите `setup`. Если создана — добавьте токен отдельно:

```sh
.venv/bin/codex-telegram-desktop set-token
```

Пустой ввод токена при настройке выбирает `TELEGRAM_BOT_TOKEN` в окружении процесса моста. Это дополнительный вариант для пользователей с уже настроенной безопасной подачей секретов. Установка не создаёт файл с открытым токеном.

Настройки по умолчанию: `~/Library/Application Support/codex-telegram-desktop`. Они отделены от CLI-режима. Если вы намеренно используете `CODEX_TELEGRAM_HOME`, задавайте один и тот же путь во всех окнах Terminal для всех команд этой установки. Не передавайте каталог настроек другим людям.

## 5. Подключите движок Desktop

Дождитесь окончания активных задач. Закройте Desktop через **Quit / Cmd+Q**; закрыть одно окно недостаточно. Скрипт не завершает приложение принудительно и откажется запускать второй экземпляр поверх работающего.

```sh
.venv/bin/codex-telegram-desktop launch
.venv/bin/codex-telegram-desktop doctor
```

`launch_requested` означает запрос запуска, а не подтверждение подключения. Дождитесь появления Desktop. Если `doctor` ещё показывает `gateway: not_connected`, откройте тестовый чат в Desktop и повторите проверку. При устойчивой ошибке используйте [диагностику](MACOS_DESKTOP.md), не переходите к отправке заданий.

Успешный `doctor` проверяет подпись, сохранённую версию движка и локальное соединение. Он не проверяет Telegram, телефон или ответ модели. Затем:

```sh
.venv/bin/codex-telegram-desktop run
```

Оставьте Terminal открытым. Ctrl+C останавливает мост; Desktop остаётся работать. Автозапуск не создаётся. Не переводите Mac в сон во время работы с телефона.

## 6. Откройте тот же чат на Samsung

В личном чате своего бота отправьте `/chats`, затем `/use номер`. Откройте `/panel` либо кнопку меню **Codex**. Проверьте прежнюю историю выбранного тестового чата. Создание чатов в этой версии выполняется в Desktop.

Когда готовы к настоящему обращению к модели, отправьте короткое безопасное сообщение с уникальной тестовой меткой. Оно должно ровно один раз появиться в исходном чате Desktop, ответ — в обоих интерфейсах. Такое задание расходует лимиты аккаунта. Точное совпадение ID чата, разрешения, остановка, сон и клавиатура проверяются отдельно по [приёмке](MOBILE_ACCEPTANCE.md).

## Смена адреса туннеля

Остановите `run` через Ctrl+C. Запустите новый туннель, замените `https://YOUR_ADDRESS` своим адресом и выполните:

```sh
.venv/bin/python scripts/configure.py --desktop --public-url https://YOUR_ADDRESS
.venv/bin/codex-telegram-desktop run
```

Повторный `setup` не требуется. Закройте прежнюю панель на телефоне и откройте `/panel` снова. Для Desktop нельзя менять sandbox этой командой: права задаются в самом приложении.

Для постоянного адреса настройте именованный туннель в своём аккаунте с origin `http://127.0.0.1:8787`, затем примените адрес тем же способом. [Руководство Cloudflare](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel/). Автозапуск и восстановление после сбоев требуют отдельной приёмки.

Обновление Desktop, смена токена и возврат к обычному запуску описаны в [MACOS_DESKTOP](MACOS_DESKTOP.md). Перед передачей файлов другим пользователям прочитайте [SECURITY](../SECURITY.md).
