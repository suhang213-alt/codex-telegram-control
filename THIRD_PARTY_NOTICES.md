# Внешние компоненты

Пакет не содержит бинарники Codex, Node.js, Python, Telegram, браузеров или туннелей. Они устанавливаются пользователем из официальных источников и имеют собственные условия использования.

| Компонент | Назначение | Поставка |
|---|---|---|
| Python | Основной runtime | Не включён |
| keyring 25.x и его зависимости | Системное хранилище токена | Устанавливается pip; лицензии в метаданных пакетов |
| Codex CLI / app-server | Локальное выполнение задач | Не включён; собственный аккаунт пользователя |
| Telegram Web App SDK | Интерфейс Telegram WebView | Загружается с `telegram.org`, локальная копия отсутствует |
| Playwright | Только тесты мобильной вёрстки | npm devDependency, в рабочем боте не нужен |
| Cloudflared либо другой HTTPS reverse proxy | Доступ телефона к loopback-серверу | Не включён; настройка пользователя |
| OpenAI Desktop plugin / native app | Только optional Windows-адаптер | Не включён и не заменяется исходниками этого проекта |

MIT в корне относится к исходникам этого проекта; не выдаёт прав на сторонние сервисы, модели, торговые марки и компоненты. Приложение является независимой интеграцией, а не официальным продуктом Telegram или OpenAI.
